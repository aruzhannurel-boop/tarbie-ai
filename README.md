# ТӘРБИЕ AI — Цифрлық тәрбие менеджері

**Дайындаған:** Таджиева Фарида Рыскелдиевна  
**Мектеп:** Қырғызсай жалпы орта білім беретін мектебі

## Орнату
1. Осы ZIP архивін компьютерде ашыңыз (Extract All).
2. GitHub `tarbie-ai` репозиторийінде **Add file → Upload files** арқылы архивтің өзін емес, ашылған папканың **ішіндегі файлдар мен `app` қалтасын** жүктеңіз. Барлық файлды таңдап, Commit changes басыңыз.
3. Vercel → Add New → Project → GitHub `tarbie-ai` → Import → Deploy.
4. Vercel → Project → Settings → Environment Variables → `OPENAI_API_KEY` қосыңыз. Құпия кілтті ешқашан GitHub-қа немесе чатқа салмаңыз. Өзгерістен кейін Redeploy жасаңыз.
5. OpenAI API үшін billing қосылған аккаунт пен жарамды API key қажет. ChatGPT Plus жазылымы API-ді қамтымайды.

## Құрамында
- 5 нақты AI модулі (серверлік OpenAI Responses API)
- 3 тапсырмалық байқау режимі
- Word (.doc), PDF (браузердің Print → Save as PDF), Excel үйлесімді CSV экспорттары
- Қазақша responsive 16:9 стиліндегі дизайн

## Маңызды шектеулер
- API кілтін орнатпайынша AI сұраулары жұмыс істемейді.
- Бұл нұсқада **дерекқор және сақталған есептер тарихы жоқ**; сессиядағы жауапты Word/PDF/CSV ретінде сақтауға болады.
- Word экспорты — Word аша алатын `.doc` HTML құжаты; толық `.docx` емес.
- Сахналық үлгі деректері «ДЕМОНСТРАЦИЯЛЫҚ ДЕРЕКТЕР» деп белгіленген.
- Жеке оқушы деректерін енгізбеңіз.
- Ашық жарияланған сайтта API сұрауларына шығын кетуі мүмкін; көпшілікке ашар алдында қосымша қолжетімділік шектеуін енгізген жөн.
